DE WURZELS – KLEURPLATEN (VS CODE / WINDOWS)

BELANGRIJK:
Open deze volledige map in Visual Studio Code via File > Open Folder.
Laat de map 'assets' naast Kleurplaten.html staan. Verplaats de afbeeldingen
niet naar een andere map en open Kleurplaten.html vanuit deze projectmap.

Bestanden:
- Kleurplaten.html
- style.css
- script.js
- planning.txt
- assets/achtergrond-voorbeeld.png
- assets/kleurplaat-1.png t/m kleurplaat-4.png

Starten:
1. Pak de ZIP uit in Verkenner.
2. Open VS Code.
3. Kies File > Open Folder en selecteer De_Wurzels_Kleurplaten_VSCode.
4. Open Kleurplaten.html.
5. Klik met Live Server op 'Go Live'.

Als je alleen de HTML-code kopieert maar de map 'assets' niet meeneemt,
verschijnt precies de kapotte afbeelding die op je screenshot te zien is.
