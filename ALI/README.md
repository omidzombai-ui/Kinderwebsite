# README.md – Puzzelpagina de Wurzels

## Wat ga ik maken?
Ik ga een puzzelpagina maken voor de website van de Wurzels. Kinderen kunnen een plattegrond kopen en puzzelstukjes verzamelen om de plattegrond compleet te maken.

## Wat ga ik doen?
- Een overzicht van de puzzels maken.
- Een plattegrond laten zien.
- Puzzelstukjes ontwerpen.
- Uitleg geven over hoe kinderen puzzelstukjes kunnen verzamelen.
- De pagina dezelfde stijl geven als de rest van de website.
- De pagina verbinden met de andere pagina's.

## Welke technieken ga ik gebruiken?
- **HTML:** voor de structuur van de pagina.
- **CSS:** voor de kleuren, afbeeldingen en vormgeving.
- **JavaScript:** voor interactieve onderdelen.



## Resultaat
Een vrolijke puzzelpagina waar kinderen kunnen ontdekken hoe ze de plattegrond compleet kunnen maken.
