# RETRO.md – Puzzelpagina de Wurzels

## Wat heb ik gedaan?
Ik heb een puzzelpagina gemaakt voor de website van de Wurzels. Op deze pagina kunnen kinderen informatie vinden over de plattegrond en de puzzelstukjes.

Ik heb HTML gebruikt voor de structuur, CSS voor het ontwerp en JavaScript voor de interactieve onderdelen.

## Wat ging goed?
- De pagina heeft dezelfde stijl als de andere pagina's.
- Ik heb de kleuren en achtergrond aangepast.
- De puzzelstukjes en voortgangsbalk toegevoegd.
- Ik heb links naar de andere pagina's gemaakt.
- Ik heb onderaan een contactknop toegevoegd.

## Wat was moeilijk?
Het was soms lastig om de CSS goed aan te passen. Ook moest ik controleren of alle links naar de juiste pagina's gingen.

## Wat heb ik geleerd?
Ik heb geleerd hoe ik een nieuwe pagina kan maken en hoe ik HTML, CSS en JavaScript samen kan gebruiken. Ook heb ik geleerd hoe ik pagina's met elkaar kan verbinden.

## Wat kan ik verbeteren?
Ik kan de puzzelpagina nog verder verbeteren. Bijvoorbeeld door de puzzelstukjes op te slaan, zodat de voortgang bewaard blijft.

## Conclusie
Ik ben blij met het resultaat. De puzzelpagina past bij de rest van de website en kinderen kunnen makkelijk zien hoe ze de puzzel kunnen maken.
