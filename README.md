# README.md – Homepage de Wurzels

## Wat ga ik maken?
Ik ga de homepage maken voor de website van de Wurzels. De homepage krijgt een vrolijke bosstijl met dieren, bloemen en bomen.

## Wat ga ik doen?
- Een logo en navigatiemenu maken.
- Een welkombericht toevoegen.
- Bewegende dieren op de homepage plaatsen.
- Knoppen maken naar andere pagina's.
- Een verjaardagsgedeelte toevoegen.
- De website geschikt maken voor mobiel.

## Welke technieken ga ik gebruiken?
- HTML voor de structuur.
- CSS voor het ontwerp en de animaties.
- JavaScript voor het mobiele menu.

## Leerdoel
Ik wil leren hoe ik een homepage maak met HTML, CSS en JavaScript.

## Samenwerken
Ik werk met Git en GitHub. Ik gebruik een eigen branch voor mijn taken en voeg mijn werk via een pull request samen met de `main`-branch.
