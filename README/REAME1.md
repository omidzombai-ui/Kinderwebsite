# Mijn taak 
Ik maak een postpagina waarop bezoekers een bericht kunnen sturen om iets te vertellen of een vraag te stellen.

# Over de pagina
De postpagina is onderdeel van onze kinderwebsite. Op deze pagina kunnen berichten worden opgestuurd.

# Doel
Een eenvoudige en gebruiksvriendelijke pagina maken waarop bezoekers gemakkelijk contact kunnen opnemen.
